# Сервер комнат кооператива (mellstroy-mp)

Отдельный воркер Cloudflare для игры по сети в «Отбейся от Интерпола» (до 4 игроков).
Старый воркер `mellstroy-lb` (рейтинг, бот, дуэли) он не трогает.

Каждая комната — Durable Object. Сервер только пересылает сообщения между игроками:
игру считает телефон хоста, остальные шлют ему управление и получают состояние мира.

## Как задеплоить (один раз, с компьютера)

1. Установи Node.js LTS: https://nodejs.org
2. Скачай папку `server/mp` из репозитория (файлы `worker.js` и `wrangler.toml`) в любую папку на компьютере.
3. Открой терминал в этой папке и выполни:
   ```
   npx wrangler login
   ```
   Откроется браузер — войди в тот же аккаунт Cloudflare, где живёт `mellstroy-lb`, и нажми **Allow**.
4. Задеплой:
   ```
   npx wrangler deploy
   ```
   В конце будет адрес вида `https://mellstroy-mp.<твой-поддомен>.workers.dev`.
5. (Необязательно) Чтобы имена игроков брались из Telegram, добавь тот же токен бота секретом:
   ```
   npx wrangler secret put BOT_TOKEN
   ```
   Токен вводится прямо в терминал — никуда его не присылай.

## Проверка

Открой в браузере `https://mellstroy-mp.<поддомен>.workers.dev/health` — должно быть `{"ok":true,"ver":1}`.
Проверь с телефона через мобильный интернет и Wi-Fi: если открывается — сеть для кооператива будет работать.

## Что умеет

- `POST /room/new` — новая комната с кодом из 5 символов.
- `GET /room/КОД/info` — кто сидит в комнате.
- `WS /room/КОД` — подключение: до 4 игроков, первый — хост; если хост вышел, хостом становится следующий.
- Во время забега новых не пускают, но вылетевший игрок может вернуться на своё место.
- Пустая комната сама очищается.
- Бесплатного плана Cloudflare хватает на десятки часов игры в день.
